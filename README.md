# 雨课堂刷课助手

当前版本：**3.1.29**（面板上显示「助手 v3.1.29」）。下面的新增功能和问题，都是在原脚本之上改出来的。

### 在原脚本上新增的功能：

- 视频按 1 倍速连续播放，不改 `video.currentTime`，避免观看记录出现灰色空档。切换页面后继续播放。
- 进入视频前检查完成标记。标题旁已经显示「已完成」，或左侧目录项已完成时，暂停并跳过，不再继续播放。
- 答题可选通义千问或 DeepSeek。配置页按卡片分开，可以测试接口是否连通。
- 作业题目先按考试字体还原文字，再联网搜索，然后交给所选模型作答。
- 按页面控件区分单选、多选和判断。判断题认勾和叉两个按钮，左边为对，右边为错。多选题少选不得分，要求把每个正确选项都选上。
- 答对后由页面自己进入下一题。答错后页面会留下「本题得分」和「正确答案」，脚本看到这块再进入下一题，不再直接跳到下一个视频。
- 讨论题读取发言框上方的正文，不读左侧课程目录。题目没有问号也会读。开启自动回复后，用所选模型按题目里的方法写一条回复并发送。已经发过言的讨论会跳过。
- 认出「请完成安全核验」后停下，等手动拖完再继续当前章节。脚本不会替用户连线。
- 面板按课程记下视频和题目轨迹。

### 目前的问题：

1. 没法跳过人机验证，答题比看视频更容易触发。窗口是「请完成安全核验」，要按住起点依次经过 1、2、3 再到终点。脚本只会停下等手动完成，弹出后当前题目会停住。
2. 答题没有续答。中途被安全核验打断、页面刷新或重新进入作业后，不会记住做到哪一题，只会处理当前屏幕上的题。
3. 流程轨迹会冲突，没有增量记录和去重。轨迹存在 `localStorage` 的 `ykt_trail` 里，按课堂分开，最多 60 条。同一节视频会先记进行中、再记已结束；题目编号带时间戳，同一题重试会多出几条；复述和所选答案改的是最近一条题目，后面又记了别的内容时可能写错卡片；「当前进度」只有一行，视频和题目会抢这一行；超过 60 条就删掉最旧的。

### 脚本使用：

点击进入要刷的**课程目录**页面（不是视频页面）点击开始刷课按钮即可自动运行，如有bug，底部有作者联系方式，可能需要大家的账号进行测试修复，如有需要可以加底部作者联系方式，感谢每一位为脚本做出贡献的用户。

### 视频怎么才算看完：

雨课堂不按「进度条走到结尾」记账，而是按播放器隔几秒上报的时间点记账。两次上报之间进度是连着走的，这段就是已观看（蓝色）；中间空了一截，就被记成拖拽，显示为未观看（灰色）。蓝色说明心跳已经送到服务器。

因此脚本按下面的方式播放：

- 默认 **1 倍速**。`playbackRate` 写在脚本配置里，可以改，但高于 1 倍时，同样几秒的真实时间里视频进度走得更多，多出来的区间可能变成灰色，覆盖率到不了 100%。
- **不修改** `video.currentTime`，不会把进度拉回开头，也不会在播放中途拖动进度条。
- 自动进入下一集后，先等新的视频出现、不再处于跳转中、并且已经读到时长，再接管。已经结束的上一集视频不会被拿来继续播。
- 1 倍速时不点倍速菜单，也不点静音按钮，只把音量设为 0。
- 缓冲或进度还在跳时不调用 `play()`。暂停后先等 15 秒；这 15 秒里进度如果自己往前走了，就不再强制播放。只有进度停住、并且数据已经准备好，才继续播放。
- 播放器到结尾后，最多再等 40 秒，看页面是否出现「已完成」或 100%。到时间还没有，就进入下一集，不卡在当前课。98%、99% 不算完成。
- 已经出现在观看日志里的灰色区间不会自动消失。从上次的截止时间接着播，只能补后面的新进度，补不了前面的空档。要补满，需要从灰色段之前连续播过那些时间。
