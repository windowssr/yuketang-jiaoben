# 雨课堂刷课助手

当前播放逻辑版本：**3.1.4**（面板上显示「助手 v3.1.4」）。

### 脚本使用：

点击进入要刷的**课程目录**页面（不是视频页面）点击开始刷课按钮即可自动运行，如有bug，底部有作者联系方式，可能需要大家的账号进行测试修复，如有需要可以加底部作者联系方式，感谢每一位为脚本做出贡献的用户。
![课程目录](/images/image.png "课程目录")

在 Edge 的篡改猴里更新脚本时，保留编辑器最上面的 `// ==UserScript==` 到 `// ==/UserScript==`，只替换这段头下面的代码。头部需要有 `// @grant unsafeWindow`。保存后强制刷新课程页，确认面板版本号。

### 视频怎么才算看完：

雨课堂不按「进度条走到结尾」记账，而是按播放器隔几秒上报的时间点记账。两次上报之间进度是连着走的，这段就是已观看（蓝色）；中间空了一截，就被记成拖拽，显示为未观看（灰色）。蓝色说明心跳已经送到服务器。

因此脚本按下面的方式播放：

- 默认 **1 倍速**。`playbackRate` 写在脚本配置里，可以改，但高于 1 倍时，同样几秒的真实时间里视频进度走得更多，多出来的区间可能变成灰色，覆盖率到不了 100%。
- **不修改** `video.currentTime`，不会把进度拉回开头，也不会在播放中途拖动进度条。
- 自动进入下一集后，先等新的视频出现、不再处于跳转中、并且已经读到时长，再接管。已经结束的上一集视频不会被拿来继续播。
- 1 倍速时不点倍速菜单，也不点静音按钮，只把音量设为 0。
- 缓冲或进度还在跳时不调用 `play()`。暂停后先等 3 秒；这 3 秒里进度如果自己往前走了，就不再强制播放。只有进度停住、并且数据已经准备好，才继续播放。
- 播放器到结尾后，最多再等 40 秒，看页面是否出现「已完成」或 100%。到时间还没有，就进入下一集，不卡在当前课。98%、99% 不算完成。
- 已经出现在观看日志里的灰色区间不会自动消失。从上次的截止时间接着播，只能补后面的新进度，补不了前面的空档。要补满，需要从灰色段之前连续播过那些时间。
